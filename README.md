LEONIDA Cover Studio — a web app that turns a photo and a caption into cover art in the style of GTA 6's posters. Drop in a photo, and the app places it in the centre of a multi-panel neon Vice City cover: helicopter, neon streets, supercar, biker chase, speedboat, swamp and vault panels around it, with a big gradient "VI" and your own title in heavy GTA-style lettering. Pick a colour grade (Sunset orange, Neon pink-purple, Teal night), switch between the 3×3 panel grid and a full-bleed hero layout, drag to reposition and zoom the photo, then export a PNG ready to share in Square (1080×1080), Portrait (1080×1350) or Story (1080×1920).

Everything is drawn in code — the panels are procedural canvas art, the sample photo is a built-in silhouette scene — so the app works fully offline from its own static files. No Rockstar logo, official artwork or fonts. Photos never leave the machine: upload, drag-and-drop and export all happen locally in the browser.

## Run it

```sh
open index.html
```

Open `index.html` in a desktop browser. No build step, no server, no network needed.
